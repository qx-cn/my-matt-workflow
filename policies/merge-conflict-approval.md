# 冲突解决边界

先读状态、两侧提交和相关要求，核对每一方意图、冲突 hunk、验证与回滚方式。用户已要求解决本次冲突时，授权内可逆、保留双方语义的本地解决可直接执行，不为每个 hunk 再问。

若双方产品行为无法兼容、必须丢失已批准意图、扩大范围或承担未授权不可逆后果，给出具体选择与影响，按当前 Skill 根目录的 `references/shared/user-intervention.md` 请求裁决。能查证的新事实继续查证，不能把任意不确定性都当暂停理由。

本地提交须有相应测试与审查证据；continue 仅在已授权本次操作且冲突解决已验证时执行。push 需要具体目标授权；危险 Git 和敏感外发遵循 [敏感操作与固定边界](enterprise-safety.md)。
