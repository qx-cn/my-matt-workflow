# 写操作边界

## 无需逐次确认

- 读取仓库与本地工具信息；
- 运行测试、类型检查和只读诊断；
- 写入已配置且被 Git 忽略的 `.agent/` 个人目录。

## 按项目配置确认

- 创建或切换分支；
- 创建 Commit；
- 修改团队跟踪的文档和配置；
- 发布 Spec/Ticket、修改 Tracker 标签或状态；
- Push、创建 PR/MR 或发送外部消息。

## 固定禁止自动执行

- Force Push；
- `git reset --hard`、`git clean` 等破坏性操作；
- 自动覆盖个人策略或未经审查合并上游变化；
- 向外部服务发送企业源码或内部信息。
