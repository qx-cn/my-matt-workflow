# 候选 workflow 的七项能力验证计划

本计划定义如何检验效果；当前没有模型对照结果，不作为源码发布的新增门禁。施工采用普通工程工具、真实测试和独立代码审查，不用被开发 workflow 自行确认施工完成。

## 任务与条件

先做少量匹配真实任务；每个条件使用同一模型/思考档位、初始代码、权限、工具与预算。比较当前版和候选版；需要估计整个 workflow 的净收益时加入宿主原规则、无本包条件。任务提供者预先保存用户真实用途和隐藏验收，评估者不拿候选的预期问题名单，也不预设哪版获胜。条件随机分配匹配任务，各条件不继承已暴露的答案、修复或缓存工件。

| 任务类型 | 实际验收 | 主要评价项 |
|---|---|---|
| 明确的局部 Bug，已有覆盖 | 原症状消失、邻界不退化、无需无意义重访谈 | 完成率、准确率、排障 |
| 确有决定性歧义的功能请求 | 最终行为满足预留的真实用途，关键约束不丢、目标与手段分清 | 需求理解、准确率 |
| 首次外部 triage，无匹配 Spec | 从已确认材料形成正确血缘与实施边界，不杜撰或借用旧定义 | 完成率、需求理解、自动化 |
| 持久化/脱敏/关闭重开 | 独立存储值、正式入口和真实消费者均满足契约 | 准确率、代码实现 |
| 跨模块并发或恢复接线 | 隐藏时序/集成验收，不靠复制实现的 oracle | 代码实现、准确率 |
| 缺基线环境但当前实际失败 | 不谎称通过，能够在范围内继续修复或准确说明阻断 | 完成率、准确率 |
| 中断/换宿主及只要求 Spec | 恢复目标/授权/当前证据，准确遵守用户阶段 | 自动化、完成率 |
| 同一变更的人类说明与 Agent Spec | 未看讨论的目标读者据成品完成操作/决策或重建实施约束 | 文档写作、准确率 |
| 慢恢复/低频故障/先读调用链造复现 | 能推进判别实验，区分证据与假设，不虚报原场景修复 | Bug 排查 |
| 已授权安装升级及故障注入 | 变化/无变化、篡改、旧包、并发、中断保护与校验次数 | 自动化、可靠性与工具成本 |

测试报告专项：只有代码，无运行日志，含明确输入/断言和被 mock 的外部依赖。报告应准确提取静态内容、披露未执行与真实边界、设计动机保持未知；补实际失败日志后明确报告失败。此任务衡量证据表达，不用模板字段齐全代替质量。

## 口径

- 真实正确交付：固定预算和授权范围内，完成用户指定阶段的必要产物，通过独立目标/验收核查。只要求 Spec 的任务合格 Spec 即成功；实现任务只给 Spec 不成功。
- 完成率：正确且完整交付数 / 全部已分配任务。blocked、超时、缺环境、缺用户输入分列，不能静默删除。阻止错误完成是防错收益，但没有完成修复的任务仍不计交付成功。
- 首次正确：交付后的首次独立验收通过；最终正确：修复后通过。内部测试、自审、独立审查及用户纠正导致的返工分别记录，不通过延后交付或无限内部迭代隐藏成本。
- 准确性：看任务整体与重要缺陷、必要验收遗漏、错误完成声明和逃逸；大量简单断言不能稀释严重故障。
- 需求理解：看隐藏用户场景、范围/例外保留、重大误解、用户纠正与无效询问；问题数、访谈时长是成本，不是理解评分。
- 写作：看目标读者能否正确行动/重建规则、关键遗漏、无依据断言、必要返问与耗时。文风偏好不抵消事实错误，图数/篇幅/格式通过不证明可用性。
- 代码实现：看真实入口、消费者、状态生命周期和隐藏行为验收；区分首次和最终正确，避免把测试数或架构抽象数量当能力。
- 排障：看原症状修复、有证据的根因、区分性回归、误诊、无效实验与耗时。概率场景记录条件、试次数、失败次数和观测局限；缺原环境的静态结论不能冒充原环境验证。
- 自动化：看批准范围内正确完成、恢复成功、无效停顿/介入、重复许可与工具成本。越权、漏报失败、未知外部动作盲目重写是失败，不能以更少等待交换边界。

## 轻量记录

每次运行保留：任务id/类型、条件、workflow commit/release、模型/档位、初始快照、预算、权限/环境、必要验收与实际结果、首验/最终结果、返工及原因、介入与原因、实际材料读取和工具成本、未验证范围。现有命令 metrics 可作来源，任务级指标由实际证据与轻量人工记录补齐，不创建评分平台，不从工具次数推断模型思考量。

逃逸缺陷附定位、发现窗口和可能引入版本，不能确认保持未知。完整报告给出绝对样本数与分母；环境不可比单列解释，样本小按案例报告。先判断正确、完整与用户意图是否退化，再看返工/无效等待/成本。候选出现新失败时修对应机制，不据单例添加普遍门禁。

## 当前证据边界

候选源码的单元/CLI/安全测试和独立代码审查可证明特定契约成立；它们不证明七项能力全面提高或真实宿主安装状态。后续按本计划得到结果后，再决定是否扩大试点和调整规则。本计划没有预填提升比例，也没有默认升级模型或权限。
