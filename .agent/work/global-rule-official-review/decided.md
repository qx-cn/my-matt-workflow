# 全局规则审查决定

- 2026-11-09：`rules/global.md` 第 5 至 6 行关于成品只保留当前有效内容、不写来源记录和作者待办的要求，仅适用于 Spec、技术方案等定稿设计文档；研究报告、审计报告和任务清单保留必要证据与待办，避免删除产物必需的信息。
- 2026-11-09：个人偏好、授权边界和 Playwright 使用规则以适用场景一致的官方最佳实践为优先依据，既有个人偏好可以重新评估；官方支持某项能力不等于推荐将其设为默认方式。
- 2026-11-09：明确授权范围内的工作在检查目标和改动后直接完成，不重复索要确认；范围扩大、关键取舍未定或出现新的高风险影响时再询问，避免无必要地中断已授权任务；宿主权限检查继续适用。
- 2026-11-09：浏览器环境按任务需要选择，公开网页与开发验证使用独立环境，只有需要本人账户或指定现有页面时才连接已授权的个人 Chrome，以减少不必要的登录态暴露；项目回归测试继续使用 Playwright Test 和隔离环境。
- 2026-11-09：个人 Chrome 任务结束后默认保留浏览器和页面，断开本任务的自动化控制连接；需要继续同一任务或用户接手交互时才保留连接，以缩短控制权限的持续时间。
