# 找用户的条件

这是工作流请求用户决定或授权的唯一清单。已确认的授权继续有效，能从代码、文件或工具查证的事实由 Agent 查证；其他可逆实施细节直接推进。

- 对齐点1：需求摘要和 quick/standard 等级；对齐点2：Spec 与逐 Ticket 行为、依赖、测试命令和测试边界。
- 用户专属决定：产品取舍、成功指标、优先级、不可逆承诺。
- Ticket 或整分支审查需要用户处理；文档审查达到上限或出现[审查停止信号](review-loop.md)。
- 推送、建 MR、写外部系统，每次都问。
- 修改 `.agent/` 之外、Spec 没有写明的项目文档。
- setup 写入前、migrate apply 前，各问一次。
- 主链之外的阶段交接：triage 到 to-tickets、wayfinder 到 to-spec、prototype 到 implement。问一次，同意后直接调用。
- 环境阻塞：说明缺少的输入或权限及最小恢复动作。

用户临时要求更严格时照做。对齐后不为执行已确认的后续阶段再次询问，也不要求用户逐段手动调用。输出用平实中文说明需决定的事项，不向用户转述内部状态名。
