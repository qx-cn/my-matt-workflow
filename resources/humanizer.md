# humanizer_policy（文档与注释）

本文件是 `humanizer_policy` 服从规则的唯一真相源。生成类 Skill 与 `my-code-review` 只通过一级指针引用此处，不复制三档定义。

## 何时加载

写入或覆盖工作产物之前加载本文件；按 `.agent/matt-workflow.md` 已解析的 `humanizer_policy` 执行。访谈提问、草稿讨论阶段不调用。

## 三档行为

- `deny`：不主动调用 `/humanizer`；可提示用户自行手动调用。
- `confirm`：先调用 `/humanizer` 标出 AI 腔或给出改写建议；**未确认不得**整篇落笔；确认后再写入或覆盖。
- `allow`：可对叙述段自动 `/humanizer` 落笔。

## 叙述段与契约段

只动**叙述段**；任何取值下都**不得改契约段**。契约段被润色会导致 Agent 执行偏离。

- **叙述段**：问题陈述、背景、利弊、「要构建什么」等给人读的说明。
- **契约段**：预设名、策略取值、验收条目、命令名、阻塞边、表格里的合法枚举值与预设字段组合，以及硬性「必须 / 不得」门禁句。

## 注释（仅 code-review）

对新增或修改的注释做文案审阅时，同样服从上表三档。保留有意简短的领域用语，不强行扩写成说明书。
