# 独立需求 Reviewer Brief

向 reviewer 提供且只提供：

- 用户原始输入，保持原样；
- 主 Agent 的理解摘要：目标、范围、明确约束、验收标准；
- 用户直接点名的最小文件或模块。

Reviewer 独立形成理解，再按四项对比：

1. 目标是否把示例、手段或类比误当任务本身；
2. 范围是否遗漏用户要求或无授权扩张；
3. 明确约束是否完整，约束之间是否冲突；
4. 是否存在会改变结果的多种合理解释。

输出 `PASS | NEEDS_CLARIFICATION | MISUNDERSTANDING`。`PASS` 只需一行；非 PASS 只列会改变目标、范围、约束或验收的原文证据、偏差和最小澄清问题，不复述原始输入或逐项输出无问题维度。只评审需求理解，不评判实现方案。需求清晰时直接 PASS，不为显示价值制造歧义。
