# 第一性原理推理

第一性原理只用于会改变采用、修改或放弃决定的承重判断。事实、假设与未知沿用[产物最终校验](artifact-finalization.md)的来源分类；谁有权决定、何时确认以及哪些约束不可覆盖，沿用[指令权威与决策 Gate](instruction-authority.md)。本参考不重新定义这两类规则。

## 因果链

先把目标写成使用者可观察的结果，区分目标与用户给出的手段、示例、类比、局部指标或既有做法。再建立：

`目标或主张 → 已分类的事实与约束 → 候选机制 → 可观察中间结果 → 用户结果`

任一箭头没有证据或无法解释，都是因果缺口。不要用更多步骤、术语或文档长度补偿断裂的因果关系。

## 最小反事实

只对承重选择比较维持现状、删除候选机制或一个更小替代方案。若更小方案在相同约束下产生同等用户结果，额外复杂度必须有可观察收益；否则它是无收益复杂度。简单、可逆且没有真实替代成本的决定不为凑数制造方案。

## 可证伪预测

为候选机制写出：若它成立，应观察到什么；出现什么结果会推翻它。验收或证据必须能捕获这个失败，而不只是证明执行过步骤。承重事实不足时返回 `unknown` 或 `inconclusive`，不把推断写成通过。

## 应用边界

各 Skill 只使用与自身决定有关的部分：需求阶段分离目标与手段，Spec 记录承重决策链，设计审查寻找反例，Ticket 阶段验证验收所有权，Skill 审查判断指令是否真正改变用户结果。专项 Skill 已经拥有的领域规则、runtime 已经强制的机械不变量，以及普通可逆细节都不在这里重复。
