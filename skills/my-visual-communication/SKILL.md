# 图示表达

用于只读审查或撰写面向人类的课程、评审报告和说明文档，且图示能够比线性文字更准确、快速地解释复杂关系时。

撰写前阅读并遵循[图示表达规则](references/shared/visual-communication.md)。该共享规则是唯一权威来源；不要在本 Skill 或产物中重复维护规则文本。

## Review 模式

用户要求 review、检查或审查已有产物时，只读评审，不修改文档或生成替代图。检查复杂结构、关系、顺序、分支、状态和差异是否因纯文字而难以理解；已有图示是否选型正确、只回答一个核心问题、紧邻对应结论，并由文字保留关键结论与约束；简单内容是否存在为画图而画图。

只报告会明显降低理解准确性或效率的问题。每项给出位置、具体理解障碍、违反的规则及最小调整方向；同一表达选择引发的多个表象合并为一项。没有合格发现时写 `No findings.`。
