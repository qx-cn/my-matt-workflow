# 阶段 B：方案对照

逐条对照第 1 步已确认的需求与当前方案。只诊断。

## 输出结构

```markdown
# 方案对照

## 对照表
| 需求条目 | 判定 | 说明 |
|---------|------|------|
| … | 直接满足 / 部分满足 / 超出范围 / 偏离需求 | … |

## 超额与偏离清单
- 超出（删 / 降级 / 保留+理由）：…
- 偏离（必须改回）：…

## 最小纠偏
1. …
2. …

## 结论
一句话：方案是否仍服务于原需求；若否，最小改动是什么。
```

## 判定（唯一合法取值）

- **直接满足**：方案覆盖该需求，无扭曲
- **部分满足**：方向对，缺口写清
- **超出范围**（超额）：多做了，与需求仍兼容
- **偏离需求**：与已确认意图不一致
