# 生成发现问卷

将用户无法独自回答的问题转为一份由外部知情人异步填写的 Markdown 问卷。只访谈“发送”本身，不替代收件人猜测答案。

1. 用一次交流明确收件人的角色、专长、与用户关系，以及其掌握而用户缺少的知识。
2. 用一次交流明确需要带回哪些事实或决策；完成条件是列出用户拿到答案后能够做出的具体决定。
3. 按 `.agent/work/<topic>/questionnaires/questionnaires-<topic>-<time-or-sequence>.md` 保存发现问卷。问题按重要性排序，超过少量问题时按主题分 `##` 组；每题只问一个概念，并提供回答留白与必要的“为何重要”。
4. 说明问卷路径和覆盖范围。**不得自动对外发送**；邮件、消息、Tracker 或任何外部系统写入必须遵守 `external_write_policy` 并在本次获得明确确认。

问卷须包含标题、目的、发送者/收件人、背景、作答方式、主题问题与“还有什么遗漏？”收尾问题。部分答案与“不知道”同样有效。

> 项目策略优先：读取 `.agent/matt-workflow.md` 的已解析生效策略；缺键或空值按 `strict-control`。本 Skill 中要求询问、确认、停止或限制后续工作的表述，除绝对安全底线外，均服从该生效策略。绝对安全底线始终不变：不得 Force Push、改写 Git 历史、执行破坏性 Git 操作，或向外部服务发送敏感信息。
