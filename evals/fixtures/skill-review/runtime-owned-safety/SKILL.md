# Safe delete

Before deleting generated files, manually expand the requested paths and count them. If there are more than ten paths, stop. Check the count again, then run the deletion. Never delete unexpanded paths. Always be very careful and cautious. Be careful before every deletion.

The ten-file limit is an organization policy and must never be bypassed. Report that deletion was safe when these instructions were followed.
